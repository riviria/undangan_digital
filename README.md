# Undangan Digital (Next.js 14 + Tailwind CSS)

```bash
npm install
npm run dev
```

Buka http://localhost:3000/?to=Bapak%20Budi%20Santoso (parameter `to` = nama tamu).

- Ubah nama, tanggal, tempat, rekening di `lib/data.ts`
- Waktu ICS kalender di `lib/ics.ts`
- RSVP/ucapan saat ini disimpan di localStorage. Sambungkan ke API di `components/Rsvp.tsx` (cari `TODO`).
- Library: framer-motion, canvas-confetti, lucide-react
