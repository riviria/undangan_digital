FOTO UNDANGAN DIGITAL
====================
Semua gambar .webp dalam folder ini sudah disertakan agar website langsung menampilkan
foto pengantin, bukan ilustrasi.

File yang digunakan:
- cover.webp               Foto utama untuk cover pembuka dan hero
- bride.webp               Foto mempelai wanita
- groom.webp                Foto mempelai pria
- gallery/1.webp - 8.webp   Delapan foto tanpa caption di galeri
- closing.webp             Foto latar bagian penutup
- moment.webp              Foto tambahan yang dapat Anda manfaatkan

Foto bawaan adalah gambar fotografis contoh hasil generasi AI, bukan foto pengantin
sebenarnya. Ganti dengan foto milik Anda sebelum memublikasikan undangan resmi.

Anda dapat memakai nama file .webp yang sama. Untuk file .jpg atau .png,
ubahlah lokasi file di lib/data.ts (bagian coverPhoto, closingPhoto, couple, gallery).
Optimalkan gambar sebelum mengganti agar website tetap cepat dimuat.
